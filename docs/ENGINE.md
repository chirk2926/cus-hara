# ゲームエンジンについて（要件#39, #43）

## 1. Godot のガイドライン（有料で配布する場合など）

| 項目 | 内容 |
|---|---|
| ライセンス | MIT ライセンス。エンジンは無料で、**有料で販売してよい**。売上に応じた支払い（ロイヤリティ）も、登録も、Godot への連絡も不要 |
| 必ずすること | ゲームの中か付属文書に、Godot のライセンス文（MIT）と著作権表示を載せる。エンジンが含むライブラリ（FreeType、ENet、mbedTLS など）の表示も含める → **ゲーム内の「ライセンス」画面で表示済み**（`main.gd` の `_show_licenses`。`Engine.get_license_text()` と `Engine.get_copyright_info()` を表示） |
| 名前とロゴ | 「Godot」の名前とロゴは商標。「Made with Godot」と書くのはよいが、Godot の公式作品や推薦と誤解される使い方はしない |
| ストアの規約 | Steam・Microsoft Store の規約は Godot とは別に守る（年齢区分、プライバシーポリシー、AI生成コンテンツの申告など）。Steam は AI を使ったゲームの申告欄がある |
| 同梱物 | フォント（OFL）はライセンス文を同梱する（`assets/fonts/licenses/`）。BGM と効果音はこのリポジトリで作ったオリジナル（`tools/make_bgm.py`、`scripts/sfx.gd`） |
| AI | Anthropic の利用規約に従う（ゲームサーバーが API を呼ぶ）。プレイヤーの入力を AI に送ることをプライバシーポリシーに書く |

公式: https://godotengine.org/license

## 2. Unreal Engine や Unity で作り直せるか

**どちらでも作り直せます。** 今は作り直していません（要件#43「今は直さなくていい」）。

### 作り直すときにそのまま使えるもの
- ゲームサーバー（`server/`）: エンジンに関係なく、HTTP と WebSocket で話すので**そのまま使える**。
- 台本・判定語・行動の表・翻訳（`data/`）: JSON なので**そのまま使える**。
- 仕様書・UIガイド・BGM・ルール（数値）: そのまま使える。

### 作り直す必要があるもの
- 3D（店内・クレーンゲーム・お客さん）、画面（UI）、1人用と対戦の進行、音声の録音と再生、台の調整のミニゲーム。

### 比較
| | Godot（今） | Unity | Unreal Engine |
|---|---|---|---|
| 費用 | 無料・ロイヤリティなし | 個人・小規模は無料（売上が一定を超えると有料プラン） | 無料。売上が一定額（作品ごとに年100万ドル）を超えた分に5%のロイヤリティ |
| 見た目 | 簡易3Dに十分 | 十分。素材ストアが豊富 | 最も高品質。このゲームの規模には重い |
| 言語 | GDScript | C# | C++ / ブループリント |
| 作り直しの手間 | ― | 中（C# で全部書き直し） | 大（作りの考え方が大きく違う） |
| 配布サイズ | 小さい（約40MB） | 中 | 大きい（数百MB〜） |
| EOS・Steam | プラグインで対応 | 公式・定番のプラグインあり | EOS は Epic 製なので最も相性がよい |

**おすすめ**: このゲームの規模（簡易3D・テキスト中心）なら Godot のままで十分。EOS を深く使いたい・見た目を大きく上げたいなら Unreal、素材ストアや求人の多さを重視するなら Unity。

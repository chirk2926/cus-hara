# 称号の案（要件#79）

称号システム用の案を100個用意しました。採用するものを番号で選んでください（例:「1〜20、35、41、90〜100」）。
名前や条件の数字を変えたいものも、番号と一緒に伝えてもらえれば直します。

- 称号は条件を満たすと手に入り、持っている称号から1つ選んで名札（タイトル画面・対戦の相手の画面）に出します。
- EOS が使えるときは、手に入れた称号を EOS の実績（Achievements）にも記録します。
- 珍しさ: ★ よくある / ★★ がんばれば / ★★★ やりこみ / 🎭 ネタ（失敗やうっかりでもらえる）
- 「1人用」は、オフライン（台本・キーワード判定）のシフトでも手に入ります（メンタルランクの経験値とは別）。採用の段階で「オンラインのときだけ」にもできます。

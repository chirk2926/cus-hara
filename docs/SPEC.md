# 仕様書 ―「カスハラ防衛線」

対象バージョン: 0.1.0（開発中）。実装済みと未実装・未検証を節ごとに明記する。数値の定義場所も併記するので、調整はそこを変える。

## 1. ゲーム概要

- ジャンル: 接客サバイバル（テキスト入力＋簡易3D）。トーンは誇張されたコメディ。
- プレイヤーは店のスタッフ。理不尽なクレームをつけるお客さんに、**キレる前に**言葉で対応する。
- 動作環境: Windows 10/11（64bit）。エンジンは Godot 4.5、レンダラーは Forward+。
- 言語: 日本語のみ。フォントは Noto Sans JP を同梱（OFL）。

## 2. ステージ（実装済み）

| ID | 名前 | 内容 |
|---|---|---|
| `konbini` | コンビニ「ハッピーマート」 | 弁当・レジ袋・年齢確認・おでん等のクレーム |
| `arcade` | ゲームセンター「ゲームパラダイス」 | クレーンゲーム中心（15台）。**景品交換は存在しない**（要件#11）。台本のお客さん9人のうち3人がクレーンゲームの客 |

共通の3D配置（全スクリプトがこの座標を前提にする）:
- 床 y=0。カメラ (0, 1.55, 1.9) から -Z 方向、FOV 60。
- カウンター: 天面 y≈1.0、x -1.6〜1.6、z 0.55〜1.05。
- お客さんの立ち位置 (0, 0, -0.35)、入口 (3.6, 0, -3.0)。

## 3. 1人用モード（実装済み・自動プレイで確認済み）

定義: `scripts/solo_game.gd`

1. 1シフト = お客さん4人（`CUSTOMERS_PER_SHIFT`）。
2. お客さんごとに2つのゲージ（0〜100）。
   - **怒り**: 開始値は30〜55（お客さんごと）。プレイヤーが返事を考えている間、毎秒
     `1.25 × patience × (1 + 0.15 × 何人目か(0始まり))` ずつ上がる。採点待ち・セリフ表示中・メニュー中は止まる。
   - **納得**: 0から始まり、正しい対応で上がる。
3. プレイヤーが返事を送ると採点され、怒り（-30〜+30）と納得（0〜+40。台本モードは最大+45）が変わる。
4. 終了条件（上から順に判定）:
   - `yielded`（不当要求を飲んだ）→ **屈した**: -600点
   - 怒り ≥ 100（時間切れ含む）→ **ブチギレ**: -300点
   - 納得 ≥ 100 → **納得**: `1000 + (100-怒り)×6 + max(0, 300 - ターン数×50)` 点
5. シフト終了時、合計点でランク（`main.gd` の `RANKS`）:
   S ≥5600 / A ≥4000 / B ≥2400 / C ≥800 / D それ未満。ステージごとにハイスコア保存。

### 入力
- 入力欄（最大200文字）＋ Enter または「返事する」ボタン。
- 定型文ボタン5種（`hud.gd` の `DEFAULT_PHRASES`）。押すと入力欄の末尾に追加される（即送信ではない）。
- Esc または「メニュー」で一時停止（つづける／タイトルへ）。

### 画面
タイトル → （ステージ選択）→ プレイ → シフト結果 → もう一度／タイトル。ほかに「遊び方」「設定」。

## 4. お客さんデータ（共通の形）

台本（`scenarios.gd`）もAI生成（`llm_client.gd`）も同じ辞書を使う。

| キー | 型 | 説明 |
|---|---|---|
| `title` | String | 呼び名（10文字程度） |
| `name` | String | 架空のフルネーム |
| `look` | Dictionary | `body_color` `skin_color` `hair_color`（#rrggbb）、`hair`（bald/short/long/perm/cap）、`build`（slim/normal/big）、`accessory`（none/glasses/mask/headphones/bag）、`height`（0.85〜1.15） |
| `memo` | String | スタッフが知っている事実と店の規定。プレイヤーへのヒント |
| `opening` | String | 最初のクレーム |
| `demand` | String | 不当な要求の要約 |
| `patience` | float | 0.7（気長）〜1.4（短気） |
| `start_anger` | int | 30〜55 |
| `solution_keywords` | Array | **台本のみ**。正しい解決策に含まれそうな語 |
| `yield_keywords` | Array | **台本のみ**。不当要求を飲んだと判定する語 |
| `lines` | Dictionary | **台本のみ**。`calm` `angry` `neutral` `demand`（配列）、`resolved` `explode` `yielded`（文字列） |

## 5. 採点

採点結果の形（両モード共通）: `anger_delta`(int) / `resolve_delta`(int) / `yielded`(bool) / `customer_reply`(String) / `comment`(String、店長の一言)。

### 5.1 台本モード（`offline_judge.gd`、実装済み）
返答に含まれる語で加減点する（部分一致）。

| 分類 | 例 | 怒り | 納得 |
|---|---|---|---|
| 謝罪 | 申し訳、すみません | -8 | |
| 共感 | お気持ち、ご不便 | -7 | |
| 傾聴 | 詳しく、お聞かせ | -5 | +8 |
| 丁寧語 | ございます、いたします | -3 | |
| 解決策（お客さんごと、最大2語） | 交換、返金 | -6/語 | +24/語 |
| 毅然とした断り | いたしかねます | 謝罪も共感も無ければ +6 | +15 |
| 言い訳 | でも、だって | +8 | |
| です・ますが無い（タメ口） | | +8 | |
| 6文字未満 | | +10 | |
| 同じ返事の繰り返し | | +12 | 0にする |
| 暴言 | うるさい、帰れ | +25 | 0にする |
| 謝罪だけを3回目以降 | | -2に固定 | |

`yield_keywords` を含み、かつ否定語（ません／かねます／お断り／無理 等）を含まない場合に `yielded = true`。「申し訳ございません」「すみません」の「ません」は否定として数えない。

### 5.2 AIモード（`llm_client.gd`、実装済み・実通信未確認）
- API: Claude Messages API（`POST https://api.anthropic.com/v1/messages`、`anthropic-version: 2026-10-21`）。
- モデル: 既定 `claude-opus-5-5`。設定画面で `claude-sonnet-5-5` / `claude-haiku-5-5` に変更可。
- `output_config.effort = "low"`、`output_config.format` にJSONスキーマを指定（構造化出力）。`max_tokens` 16000。
- Opus/Sonnet 5.5 では拒否時フォールバック（`fallbacks: "default"`、ベータヘッダ `server-side-fallback-2026-07-01`）を付ける。400が返ったら外して1回だけ再試行。
- 呼び出しは2種類: お客さん生成（1人につき1回）と、1ターンの採点（返事1回につき1回）。
- 失敗時: お客さん生成に失敗 → 台本のお客さんに切替。採点に失敗 → そのターンだけキーワード採点。どちらも画面に理由を表示。
- APIキー: 設定画面で入力し `user://settings.cfg` に**平文**保存。空なら環境変数 `ANTHROPIC_API_KEY`。
- プロンプト全文は `llm_client.gd` の `GM_SYSTEM` / `GEN_SYSTEM`。プレイヤー入力に含まれる命令には従わない旨を明記している。

## 6. 対戦モード（実装済み。IP直結は自動テスト済み、Steam接続は未検証）

定義: `scripts/versus_game.gd`（進行）、`scripts/net_session.gd`（接続）。要件#12, #15, #16。

### 6.1 つなぎ方
タイトル →「対戦する」でロビー画面を開く。

| 方法 | 内容 | 状態 |
|---|---|---|
| フレンドを招待（Steam） | フレンド限定の部屋を作り、Steamの招待画面を開く | GodotSteam を入れたビルドでのみ有効。**実機未検証** |
| ランダムマッチ（Steam） | 空いている公開部屋を探して入る。無ければ自分で公開部屋を作って待つ。レーティングが近い部屋を優先 | 同上 |
| IPアドレスで対戦 | 一方が「部屋を作る」、もう一方が相手のIPを入れて「参加する」。ポート 24545（UDP） | CIで自動対戦を確認済み |

GodotSteam が入っていないビルドでは、Steamの2つのボタンは押せない状態で表示される。

### 6.2 試合の流れ
- 2人。1試合 = 2ラウンド。ラウンドごとに客役と店員役を交代する（最初の役は抽選）。ステージも抽選。
- 進行と判定はすべてホスト（部屋を作った側）が行う。ゲストは入力を送り、結果を表示するだけ。
- お客さんカード（人物・状況メモ・不当な要求）は台本（`scenarios.gd`）から抽選し、両者に見える。
- 1ラウンドの手順:
  1. 客役が最初のクレームを書く（35秒）。空のまま・時間切れならカードの文面を使う（ペナルティなし）。
  2. 店員役の番。考えている間、怒りが毎秒 `1.1 × patience` 上がる。100で時間切れ（客役の勝ち）。
  3. 店員の返答を採点（1人用と同じ。ホストにAPIキーがあればAI、なければキーワード採点）。
  4. 客役の番（25秒）。言い返すセリフを書く。審判が評価する（下表）。
  5. 2〜4 をくり返す。

客役のセリフの評価（`offline_judge.gd` の `judge_customer_line`。常にキーワード判定）:

| セリフ | 効果 |
|---|---|
| 筋の通った圧力（長さ、「！」、不当要求の語、「責任者」「誠意」などで加点） | 怒り +3〜+12 |
| 無言・時間切れ | 納得 +12（店員側に有利） |
| 度を越した暴言（「死ね」「殺す」など） | 納得 +15 |
| 同じセリフの繰り返し | 納得 +8 |

### 6.3 勝敗
- ラウンド: 納得100 → 店員役の勝ち。怒り100・時間切れ・店員が不当要求を飲む → 客役の勝ち。8往復で決着しなければ、納得 > 怒り なら店員役、そうでなければ客役の勝ち。
- ラウンドの得点（勝った側だけ）: 店員役 `100 + (100 - 怒り)`、客役 `100 + (100 - 納得)`。
- 試合: 2ラウンドの得点合計が多い方の勝ち。同点は引き分け。
- 試合中に相手が切断したら、残った側の勝ち。メニューから「対戦をやめる」を選ぶと相手の勝ちになる。対戦中は時間が止まらない。

### 6.4 レーティングとランク（`game_settings.gd`）
- Elo方式。初期値1000、K=32。`期待勝率 = 1 / (1 + 10^((相手 - 自分) / 400))`、`増減 = 32 × (結果 - 期待勝率)`（勝ち1 / 引き分け0.5 / 負け0）。
- ランク名: 〜899 研修生 ／ 900 アルバイト ／ 1050 バイトリーダー ／ 1200 副店長 ／ 1350 店長 ／ 1500 エリアマネージャー ／ 1700 伝説のクレーム処理班。
- レーティング・勝敗数は各自のPCの設定ファイルに保存する。**書き換えれば改ざんできる**（サーバーでの検証は無い）。
- タイトル画面とロビーに現在のレーティングとランク、対戦結果画面に増減を表示する。

### 6.5 まだ無いもの
- 客役のセリフのAI採点、観戦、再戦ボタン（結果画面からロビーへ戻る導線はある）、Steamリーダーボードへの送信。
